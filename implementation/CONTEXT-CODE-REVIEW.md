## Review findings requiring a domain or release decision

- Chart speed is currently classified with a zero comparison. A domain reviewer must select and version the near-station tolerance; do not invent it during engineering cleanup.
- Chart unit tests exercise invariants and concurrency, not independent expected planetary positions. Obtain rights-compatible reference data and reviewer approval before accuracy claims.
- The production reviewed-rule set and labeled expert evaluation are empty. The app conservatively returns source material and abstains rather than claiming those requirements are satisfied.
- No provider, Google production client, licensed books, public Python host, or recovery-tested privacy executor is configured. The synthetic local app and static Pages guide must not be described as a live public astrology service.
