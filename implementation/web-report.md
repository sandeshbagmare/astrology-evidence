# Web implementation report

Implemented the Jinja application routes, local CSS/JavaScript, and ordinary HTML form adapters. Pages include landing/login/dashboard, create/edit/delete profiles, chart calculation and accessible fact table, reading creation/list/detail/deletion, public source library, privacy settings, and curator JSON import/publish/withdraw.

All mutations reuse the existing API functions and Pydantic inputs. The form adapter preserves the request Origin and cookies and translates the submitted CSRF token into the API header; authorization remains enforced by each API. Dev-login form uses a browser-bound one-use state. Reading HTML invokes the same rights-rechecking read service as JSON; withdrawn evidence cannot bypass publication checks. Chart HTML invokes owned active-profile checks. Library excerpts only come from CorpusService.source for active published manifest members.

Profile and reading forms work without JavaScript and preserve user input on validation errors; JavaScript enhances JSON submission with stable reading idempotency keys. Settings support consent grant/revoke, export request/status/download, logout and confirmed deletion. Export polling recognizes succeeded, failed, dead_letter and cancelled, with a normal refresh link fallback. Curator JSON import is functional; PDF/OCR is explicitly not offered by this UI because there is no PDF backend.

Verification: 14 focused web tests pass, covering HTTP rendering, escaping, login redirects, no-JS profile create/edit, uncertainty, CSRF/origin checks, escaped validation input, logout revocation, export job creation, admin authorization, unpublished/withdrawn source filtering and HTML 410 for withdrawn reading evidence. `node --check src/astrology_evidence/web/static/app.js` passed. Full earlier suite had eight calculation failures caused by missing swisseph in Python 3.14; the parent is responsible for final integrated supported-runtime verification. Browser keyboard/contrast checks have not been completed in this subtask; no WCAG conformance claim is made.
